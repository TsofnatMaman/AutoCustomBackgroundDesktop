## שינוי רקע מסך הנעילה (Issue #14)

ניתן לבחור בקובץ `Src/config.json` את היעד בשדה `wallpaper.applyTo`:

- `desktop` – רק שולחן העבודה (ברירת מחדל; גם אם השדה חסר).
- `lockScreen` – רק מסך הנעילה של Windows.
- `both` – שולחן העבודה ומסך הנעילה.

לדוגמה: `"applyTo": "both"` תחת `wallpaper`. אותה תמונה עם הספירה לאחור תשמש לשני היעדים. העדכון של מסך הנעילה משתמש ב־Windows Runtime API ועשוי להיחסם על ידי מדיניות המחשב או מגבלות Windows. במקרה של כשל, ניתן לבדוק את היומן בתיקיית `cache` והעדכון לשולחן העבודה לא ייחסם. יש לבצע בדיקה במחשב Windows 10/11 לפני הפצה.
