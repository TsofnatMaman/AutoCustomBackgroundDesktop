## שינוי רקע מסך הנעילה (Issue #14)

יוצר הפרויקט בוחר יעדים בקובץ `Src/config.json` באמצעות `wallpaper.targets`:

- `"desktop": true` – עדכון שולחן העבודה.
- `"lockScreen": true` – עדכון מסך הנעילה.
- ניתן להפעיל כל אחד מהם בנפרד, את שניהם, או אף אחד.

לדוגמה: `"targets": {"desktop": true, "lockScreen": true}` תחת `wallpaper`. תצורות ישנות נשארות עם ברירת מחדל של שולחן העבודה בלבד. אותה תמונה עם הספירה לאחור תשמש לשני היעדים. העדכון של מסך הנעילה משתמש ב־Windows Runtime API ועשוי להיחסם על ידי מדיניות המחשב או מגבלות Windows. במקרה של כשל, ניתן לבדוק את היומן בתיקיית `cache` והעדכון לשולחן העבודה לא ייחסם. יש לבצע בדיקה במחשב Windows 10/11 לפני הפצה.
